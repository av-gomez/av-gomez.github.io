Qué hice

Un servidor MCP en Python para buscar series, descargar datos, resumir y comparar. Cada número viene con el código de la serie, el periodo y la URL de las estadísticas del BCRP. Las cuentas las hace Python, no el modelo.

La prueba usó 10 preguntas sobre cifras recientes con Claude Haiku. Con el mismo enfoque hice un servidor para indicadores del Banco Mundial.
