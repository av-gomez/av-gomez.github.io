Qué hice

La tesorería llena un Excel por mes y escribe en config_mes.py para qué fue cada gasto. build.py lee los Excel, calcula ingresos, egresos operativos, inversión y saldo, y genera el sitio estático. GitHub Actions lo publica en cada push.

El script comprueba que el saldo final de cada mes sea el saldo inicial del siguiente. Cada mes trae su Excel descargable para revisar línea por línea. El README está escrito para personas que no programan.
