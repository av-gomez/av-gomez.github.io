What I did

A Python MCP server to search series, download data, summarize and compare. Each number comes with the series code, the period and the URL of the BCRP statistics. Python does the math, not the model.

The test used 10 questions on recent figures with Claude Haiku. With the same approach I made a server for World Bank indicators.
