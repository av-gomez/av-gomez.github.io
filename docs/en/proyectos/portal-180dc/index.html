What I did

The treasury fills in one Excel file per month and writes in config_mes.py what each expense was for. build.py reads the files, computes income, operating expenses, investment and balance, and generates the static site. GitHub Actions publishes it on every push.

The script checks that each month's closing balance equals the next month's opening balance. Every month has a downloadable Excel file to review line by line. The README is written for people who do not code.
